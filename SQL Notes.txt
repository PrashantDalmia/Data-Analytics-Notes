14 - 14. What is a Correlated Subquery? A subquery that depends on the outer query row-by-row. Runs once per row, making it slower.
	Example - Find employees whose salary is greater than the average salary of their department.

			SELECT e.employee_id, e.name, e.department, e.salary
			FROM employees e
			WHERE e.salary >
				  (
					SELECT AVG(e2.salary)
					FROM employees e2
					WHERE e2.department = e.department
				  );

25 - Date/Time related questions:-
A)Running total but restart every month
Answer:
SELECT
    order_id,
    order_date,
    amount,
    SUM(amount) OVER(
        PARTITION BY DATE_TRUNC('month', order_date)
        ORDER BY order_date
    ) AS monthly_running_total
FROM orders;
B)Moving average over last 7 days
Answer:
		SELECT date,
			   amount,
			   AVG(amount) OVER(
				   ORDER BY date
				   ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
			   ) AS moving_avg_7day
		FROM sales;

C) Find Customers with NO transactions in the last 3 months
Answer:
		SELECT c.customer_id, c.name
		FROM customers c
		LEFT JOIN transactions t
			ON c.customer_id = t.customer_id
		GROUP BY c.customer_id, c.name
		HAVING MAX(t.txn_date) < CURRENT_DATE - INTERVAL '3 months'
		   OR MAX(t.txn_date) IS NULL;
D) Find Inactive Customer (NoOrder in last 6 months)

36 - Self JOIN - When table joins itselfs
		Use cases:
				comparing one row to another row in the same table	
				finding previous/next values
				finding duplicates	
				finding hierarchical relationships (manager → employee)
A) Employee Manager Mapping

| ------ | ----- | ---------- |
| 1      | Asha  | NULL       |
| 2      | Rohan | 1          |

    e.name AS employee,
    m.name AS manager
FROM employees e

    ON e.manager_id = m.emp_id;
