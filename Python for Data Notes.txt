It allows:

Easy filtering, grouping, aggregating, merging

4. Difference between loc[] and iloc[] in Pandas?

Answer:
loc[] → Label-based selection (by column/row name)
iloc[] → Index-based selection (by position)

df.loc[0, 'column_name']    # by label
df.iloc[0, 1]               # by index

5. What is vectorization and why is it preferred in data processing?

Answer:

Vectorization means performing operations on entire arrays rather than iterating through elements.
It uses NumPy’s C-level optimizations, making code much faster.

Example:

df['total'] = df['price'] * df['qty']  # vectorized

vs

for i in range(len(df)):               # slow loop
    df['total'][i] = df['price'][i] * df['qty'][i]

✅ Preferred for performance and readability in analytics pipelines.

4. Changing datatypes → astype()

7. How do you handle missing data in Pandas?

Answer:

Drop rows/columns: df.dropna()
Fill with a constant: df.fillna(0)
Forward/Backward fill: df.fillna(method='ffill')
Group-wise imputation:
df['sales'] = df.groupby('region')['sales'].transform(lambda x: x.fillna(x.mean()))

✅ Choose method based on business context and data pattern.

12. What is multiprocessing in Python? Why is it used in ETL?

Answer:
Python’s multiprocessing allows you to run tasks in parallel using multiple CPU cores.
Used in ETL to process files, API calls, or database inserts concurrently.

Example:

from multiprocessing import Pool
with Pool(4) as p:
    p.map(process_file, file_list)

✅ Boosts performance in large-scale batch jobs.

13. What are Python decorators and where are they used in data pipelines?

Answer:

Decorators modify behavior of functions without changing their code.
Common in logging, timing, retry mechanisms.

Example:

def log_decorator(func):
    def wrapper(*args, kwargs):
        print("Running", func.__name__)
        return func(*args, kwargs)
    return wrapper

@log_decorator
def etl_job(): print("ETL running...")

✅ Used for logging job execution or timing ETL steps.

14. Explain difference between shallow and deep copy.

Answer:

Shallow Copy: Copies references → changes affect original.
Deep Copy: Creates entirely new objects.


import copy
a = [[1,2],[3,4]]
b = copy.deepcopy(a)
b[0][0] = 99
print(a)  # unchanged

✅ Useful in data transformations to prevent unintended data mutation.

15. What are Python generators and why are they important in ETL?

Answer:
Generators use yield to produce values lazily.
They don’t load all data into memory — great for large datasets.

Example:

def read_large_file(file_path):
    with open(file_path) as f:
        for line in f:
            yield line

✅ Common DE use case: Reading large logs or streaming data efficiently.

26. Python Shor Notes

1. Handle Missing Data & Duplicate Data

df.isnull().sum()          # Count nulls per column
df.dropna()               # Drop rows with missing values
df.fillna(method='ffill') # Fill missing values
df.drop_duplicates()      # Remove duplicate rows
df.replace({'old':'new'}) # Replace values in dataframe

2. Inspect & Understand Your Data

df.head()     # Shows first rows of data frame
df.info()     # Displays dataframe info and data types
df.describe() # Shows summary statistics

3. Rename, Convert & Clean Columns

df.rename(columns={'old':'new'}) # Rename columns
df.astype({'col':'type'})        # Change data type of column
df.drop(['col'], axis=1)         # Drop one or more columns
df.reset_index(drop=True)        # Reset index, drop old index
df.columns.str.strip()           # Strip whitespace from column names

4. Filter, Slice & Select Rows

df.loc[df['col'] > value]               # Filter using condition
df.iloc[0:5]                            # Select rows by index
df['col'].isin(['val1','val2'])         # Filter using multiple values
df.query("col > 10 & col2 == 'yes'")    # Query with expressions

5. Merge & Group Data

pd.concat([df1, df2], axis=0)       # Concatenate rows
pd.merge(df1, df2, on='key')        # Merge on key
df.groupby('col').agg({'val':'mean'}) # Group & aggregate
df['col'].value_counts()            # Frequency of unique values
df.pivot_table(values, index, columns) # Pivot table
