✅ 1. JOIN vs BLENDING vs RELATIONSHIP

Blending
Blending happens at sheet level meaning in one sheet you can have different connection but in other sheet you can have different connection
The number are aggregated one the basis of primary data source
Has separate canvas for the different data sources
Used when data comes from different data sources (SQL + Excel etc).
No physical join → Tableau matches data on the fly using a common field.
Primary data source (blue), secondary source (orange).
Slow because it sends multiple queries.

Joins
The physical layer
The tables created from this is a static table
Way to handle duplication is LODs
Have a single canvas for the data source
Happens inside Tableau data model before visualization.
Combines rows horizontally based on a join condition (A.ID = B.ID).
Creates one single table.
Fastest when both tables come from the same database.
Risk: Can duplicate rows (especially in one-to-many joins).


Relationship
The Logical Layer
More flexible
Contextual join
Have a single canvas but separated by data source within canvas
Introduced in recent Tableau versions.
Flexible join → Tableau automatically chooses join type depending on viz.
Prevents duplication → maintains separate logical tables.
Best practice for modern dashboards.

Note - Joins are faster. Relationships give flexibility and avoid data duplication, but they add extra query processing, making them slower compared to regular database joins.

✅ 3. Types of LOD Expressions + Simple Examples

LODs
Fixed - Static
Dynamic - Include, Exclude

FIXED - Ignores view level of detail; uses the dimension you mention.
Example - {FIXED CustomerID : SUM(Sales)}
→ Sales per customer, even if customer is not in the view.

INCLUDE - Adds extra dimension to the view.
{INCLUDE Product : SUM(Sales)}
→ Sales per product even if product is not displayed.

EXCLUDE - Removes a dimension from the view.
{EXCLUDE Month : SUM(Sales)}
→ Gives yearly total even when months are visible.

Notes:-
If we use Exclude LOD, we are going high level of Aggregation and less level of details like from button to top
If we use Include LOD, we are going lower level of Aggregation and more level of details like from top to bottom

✅ 18. Table Calculations

RUNNING_SUM()
Meaning:-
Adds values row by row (cumulative sum).
Formula:-
RUNNING_SUM(SUM([Sales]))
Example:-
If sales = 10, 20, 30 → Running sum = 10, 30, 60.
Use Case:-
Cumulative totals, YTD metrics, progressive growth.

2 - RUNNING_AVG()
Meaning:-
Average of all rows from start till the current row.
Formula:-
RUNNING_AVG(SUM([Sales]))
Example:-
Sales = 10, 20, 30 → Running avg = 10, 15, 20.
Use Case:-
Trend smoothing over time.

3- LOOKUP()
Meaning:-
Fetches a value from a previous or next row.
Formula:-
LOOKUP(SUM([Sales]), -1)   // previous row
LOOKUP(SUM([Sales]), 1)    // next row
Example:-
Use to compare current month vs previous month.
Use Case:-
Month-over-month change, difference from previous row.

4 - WINDOW_SUM() / WINDOW_AVG()
Meaning:-
Performs calculation over a **window (range of rows)**, not cumulative.
Formulas:-
WINDOW_SUM(SUM([Sales]))
WINDOW_AVG(SUM([Sales]))
Example:-
If your window is last 3 months → rolling 3-month total or average.
Use Cas:-
Moving averages, rolling totals, sliding windows.

5 - PERCENT_OF_TOTAL()

Meaning:-
Shows each row/value as a percentage of the entire total.
Formula:-
SUM([Sales]) / WINDOW_SUM(SUM([Sales]))
Example:-
Category A = 40, B = 60
A% = 40/100 = 40%
B% = 60/100 = 60%.
Use Case:-
Contribution analysis (category share, market share).

6 - RANK()
Meaning:-
Ranks the values in ascending or descending order.
Formula:-
RANK(SUM([Sales]), 'desc')
Example:-
Sales: 100, 80, 50 → Rank = 1, 2, 3.
Use Case:-
Top N customers, top products, performance ranking.

7 - INDEX()
Meaning:-
Gives the **row number** in the partition.
Formula:-
INDEX()
Example:-
Rows → 1, 2, 3, 4…
Use Case:-
Creating row numbers
Pagination setups
Filtering based on row number (Top N).

A single-line cheat sheet:-

| Calculation          | Simple Meaning               | Example Formula                           |
| -------------------- | ---------------------------- | ----------------------------------------- |
| **RUNNING_SUM**      | Cumulative total             | `RUNNING_SUM(SUM([Sales]))`               |
| **RUNNING_AVG**      | Cumulative average           | `RUNNING_AVG(SUM([Sales]))`               |
| **LOOKUP**           | Current vs previous/next row | `LOOKUP(SUM([Sales]), -1)`                |
| **WINDOW_SUM**       | Rolling total in a window    | `WINDOW_SUM(SUM([Sales]))`                |
| **WINDOW_AVG**       | Rolling average in a window  | `WINDOW_AVG(SUM([Sales]))`                |
| **PERCENT_OF_TOTAL** | Row % of total               | `SUM([Sales]) / WINDOW_SUM(SUM([Sales]))` |
| **RANK**             | Rank values                  | `RANK(SUM([Sales]), 'desc')`              |
| **INDEX**            | Row number                   | `INDEX()`                                 |

✅ 22. Tableau Server

1. What is Tableau Server?
A platform to publish, share, schedule, and manage Tableau dashboards securely for enterprise use.

2. Key components of Tableau Server?
Gateway, VizQL Server, Application Server, Data Engine, Backgrounder, Repository.

3. What is the role of Backgrounder?
Runs extract refreshes, subscriptions, and scheduled tasks.

4. Difference between Live and Extract on Server?
Live:Real-time query to database.
Extract:Cached data, faster, supports scheduling.

5. How do you manage permissions?**
Set at project/workbook/view/data source levels; deny overrides allow.

6. What authentication methods are supported?
AD/LDAP, SAML, Kerberos, OAuth.

7. How do you implement Row Level Security (RLS)?
Use user filters or entitlement tables linked with usernames from Tableau Server.

8. How do you monitor performance?
Use Admin Views or query the Tableau Server Repository (Postgres DB)

9. What is High Availability (HA) in Tableau Server?
Multi-node setup with redundant repository and clustered components for failover and performance.

10. How do you perform backup & restore?
Backup:`tsm maintenance backup`.
Restore:`tsm maintenance restore`.

11. What is VizQL Server?
Processes queries and renders visualizations for users.

12. How do you improve server performance?
Use **extracts**, optimize queries, reduce filters, increase hardware resources, and monitor background tasks.
